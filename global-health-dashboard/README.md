# Global Health Dashboard

Tableau dashboard analysing global health indicators across countries and regions.

## Project Objective

Analyse relationships between life expectancy, BMI, cholesterol levels and population trends.

## Tools Used

📊 Tableau Public  
📈 Data visualisation  
📉 KPI analysis  

## Key Questions

- Which regions have higher life expectancy?
- How does BMI vary across countries?
- Is there a relationship between cholesterol and health indicators?
- Population distribution trends

## Dashboard Features

- Interactive filters
- Regional comparisons
- KPI cards
- Trend visualisations

## Key Insights

- Regions with higher healthcare indicators tended to show higher life expectancy.
- Population density varied significantly across regions.
- BMI and cholesterol patterns showed regional differences.
