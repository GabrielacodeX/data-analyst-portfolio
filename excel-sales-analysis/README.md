# Excel Retail Sales Analysis

Excel project exploring retail sales data using formulas, filtering, conditional formatting and PivotTables.

## Project Objective

Analyse retail sales performance, customer trends and product categories using Excel.

## Tools Used

📄 Excel  
📊 PivotTables  
📈 Charts  
🎛 Slicers  
🎨 Conditional Formatting  

## Skills Demonstrated

- Data filtering & sorting
- SUM and AVERAGE formulas
- Conditional formatting
- PivotTables
- Sales analysis
- Business insights

## Key Findings

- Calculated commission totals and averages
- Explored customer age and product categories
- Used PivotTables to analyse profitability by country and customer groups
- Identified customer patterns across markets
